# NYC Airbnb Data Summary Tool

**Course:** CPSC-620-3 Agile Software Development  
**Group:** Group 3

## Sprint Goal

Develop a functional Python tool to clean, process, and summarize NYC Airbnb listing data using Agile practices.

## Project Overview

This project uses the `Airbnb_NYC.csv` dataset to generate meaningful summaries of Airbnb listings, including prices, room types, neighbourhoods, and availability.

## Team Collaboration

Group 3 will complete one mini sprint using GitHub and GitHub Projects.

Each team member will work on a separate feature branch, make meaningful commits, and submit pull requests for peer review before merging into the main branch.

## Project Structure

The project will include reusable Python functions for data cleaning and analysis.

## How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Run the Python scripts to clean and summarize the dataset.
